# Roadmap del progetto

## Fase 1: Preparazione dati
- Creazione dataset simulato
- Verifica struttura dati (colonne, tipi)

## Fase 2: Preprocessing
- Gestione valori mancanti
- Normalizzazione variabili numeriche
- Encoding variabili categoriche

## Fase 3: Analisi statistica
- Statistiche descrittive (media, varianza)
- Visualizzazioni (istogrammi, boxplot)
- Analisi correlazioni

## Fase 4: Modellazione predittiva
- Regressione logistica
- Random Forest
- Valutazione modelli (accuracy, confusion matrix)

## Fase 5: Interpretazione risultati
- Analisi importanza variabili
- Generazione report testuale
- Visualizzazione risultati

## Fase 6: Output finale
- Grafici finali
- Report interpretabile
- Prototipo pronto per demo
