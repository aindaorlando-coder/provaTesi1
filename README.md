# 🌍 Pipeline automatizzata per dati ambientali

## 📌 Obiettivo
Prototipo di pipeline per analisi e previsione della qualità dell’aria.

## 📊 Dataset
- datasetDelhi.csv
- dataset_simulato.csv

## ⚙️ Pipeline
1. Acquisizione dati
2. Preprocessing
3. Analisi esplorativa (EDA)
4. Modellazione predittiva
   - Linear Regression
   - Random Forest Regression
5. Valutazione modelli

## 🧠 Risultati
Confronto tra modelli e analisi delle performance.

## 📁 Struttura progetto
- /data → dataset
- /notebooks → analisi e modelli
- /reports → report finale
