# Progetto: Pipeline automatizzata per dati ambientali

## Obiettivo
Creare un prototipo di pipeline automatizzata per analisi e predizione della qualità dell’aria, utilizzando:
- **GSD** per orchestrare i task della pipeline
- **OpenCode.ai** per generazione automatica del codice
- **Ollama** per interpretazione dei risultati e generazione di report

## Dataset
- Dati simulati: PM2.5, NO₂, Temperatura, Umidità, Indice qualità aria (Buono/Cattivo)
- 100 righe per test del prototipo

## Fasi del progetto
1. Acquisizione dati
2. Preprocessing (gestione valori mancanti, normalizzazione)
3. Analisi statistica (grafici, medie, correlazioni)
4. Modellazione predittiva (regressione logistica, Random Forest)
5. Report finale e interpretazione dei risultati
